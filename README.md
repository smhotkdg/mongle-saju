# 몽글사주 🐹

귀여운 햄스터 점술사 ‘몽글도사’가 운영하는 React + Tailwind CSS 웹사이트입니다. 한국 음력과 절기를 반영한 사주 원국을 계산하며, 결제만 데모입니다. 크림색, 피치핑크, 라벤더를 사용한 모바일 우선 반응형 디자인입니다.

## 실행

Node.js 22.12 이상이 필요합니다. Node.js 24에서 빌드와 실행을 확인했습니다.

```sh
npm install
npm run dev
```

브라우저에서 http://127.0.0.1:5173/ 를 열어주세요. 파일 저장 시 다시 빌드하고 화면을 자동으로 새로고침합니다. 입력 중인 폼은 새로고침 시 초기화됩니다.

일반 환경에서 Vite의 빠른 HMR 개발 서버를 선호하면 `npm run dev:hmr`도 사용할 수 있습니다. 기본 개발 서버는 Windows 샌드박스에서도 동작하도록 빌드 감시 방식을 사용합니다.

```sh
npm run build
npm run preview
npm test
```

pnpm을 사용하는 경우 위의 `npm` 대신 `pnpm`으로 실행해도 됩니다. pnpm 사용 시 포함한 잠금 파일로 동일한 버전을 설치할 수 있습니다.

## 구현된 기능

- 오늘의 무료 운세: 한국 날짜의 실제 일진을 계산하고, 출생 일간과 오늘의 천간 사이 십성을 풀이합니다. 임의 점수는 사용하지 않습니다.
- 편한 생년월일 입력: 연도 숫자 직접 입력 + 월·일 선택. 양력 윤년과 월별 일수, 한국 음력의 29·30일 및 윤달을 반영합니다. 실제 없는 날짜나 미래 날짜는 거절합니다.
- 편한 출생 시간 입력: 오전·오후 + 시 + 분 선택. 자정·정오 안내와 ‘시간 모름’ 입력 생략을 지원합니다. 기존 선택은 ‘시간 모름’을 해제하면 복원됩니다.
- 한국 양력·음력 변환, 평달·윤달 선택. 없는 윤달은 왕복 변환 검증으로 거절합니다.
- 실제 년주·월주·일주·시주, 일간, 천간·지지 대표 오행 개수.
- 시간 미상일 때 시주를 만들지 않습니다. 절기·일주 경계일은 가능한 원국 후보와 오행 개수 범위를 표시합니다.
- 기본 사주 결과 → 990원 데모 해금 화면 → 8개 챕터의 개인 리포트. 10가지 일간 캐릭터와 5종 오행 삽화, 강점·에너지 패턴, 직무 예시 3가지, 회사 대화·관계·생활 습관·계절 이야기, 체크 가능한 7일 실험을 제공합니다.
- 취업 준비·회사 생활·이직 고민·프리랜서·학생 상황을 직접 선택해 구체적인 장면과 행동 제안을 읽습니다. 원국의 다른 천간 십성에 따라 직무 예시와 일의 테마가 달라집니다. 일간을 확정할 수 없으면 개인 캐릭터를 만들지 않으며, 다른 천간이 모두 불확실하면 직무를 일반 탐색 예시로 표시합니다.
- 오늘의 운세에는 실제 십성에 맞춘 3개 장면 카드를, 궁합에는 두 캐릭터 삽화와 약속·답장·서운함 등 대화 장면을 제공합니다.
- 연인·친구·전 애인 궁합: 두 사람의 실제 일주로 일간의 오행 관계, 일지의 육합·충을 비교합니다. 관계 종류는 대화 제안에만 반영하며 합·충 계산은 동일합니다. 성공·재회 확률을 만들지 않습니다.
- 1080 × 1350 PNG 결과 카드 미리보기·다운로드, 지원되는 모바일의 파일 공유, 결과 링크 복사.
- 내 운세 서랍: 닉네임·원국 글자·풀이·선택한 상황·실천 체크·선택한 부적과 응원 도장을 브라우저에 최대 20개 보관하고 개별 삭제합니다. 입력한 출생 날짜·시각과 변환한 달력 날짜는 저장하지 않습니다.
- 모바일 하단 메뉴, 키보드 사용 가능한 모달, FAQ, 개인정보 안내.

## 계산 기준과 검증

1. `korean-lunar-calendar@0.4.0`의 한국 음력 데이터를 사용합니다. 중국 음력을 음력 변환에 사용하지 않습니다.
2. `lunar-javascript@1.7.7`로 절기 시각을 계산합니다. 라이브러리의 UTC+8 시각과 한국 표준시 UTC+9의 1시간 차이를 보정합니다. 년주는 입춘, 월주는 12절의 절입 순간에 바뀝니다. 음력 설날을 년주 경계로 사용하지 않습니다.
3. 일주는 한국 양력 날짜의 일진으로 계산합니다. 자정(기본) 또는 밤 23시(자시) 경계를 선택할 수 있습니다. 시지의 2시간 구간과 선택한 일간의 오서둔 규칙으로 시간 천간을 계산합니다. 자정 기준의 23시는 당일 일간을 쓰며, 23시 기준은 다음 날 일간을 씁니다.
4. 십성은 일간과 상대 천간의 오행 생·극 및 음양 관계입니다. 오행 분포는 천간과 지지 대표 오행을 각각 1개로 센 값입니다. 지장간, 계절 가중치, 조후, 신강·신약 및 용신 판정은 제공하지 않습니다.
5. 입력 범위는 1900년부터 오늘까지입니다. 달력 모듈은 2050년까지 지원합니다. 시간 미상은 시주를 제외하고, 경계 시각 전후의 원국을 계산해 가능한 후보를 표시합니다.

검증 자료: [한국천문연구원 2026년 공개 달력자료](https://astro.kasi.re.kr/kor/life/post/calendarData?search_year=2026). 이 페이지 자체는 공식 월력요항 발표 전 자료라고 명시합니다. 해당 자료의 음력 월초 12개 날짜와 일진을 대조했고, 24절기의 계산 시각은 공개된 분 단위 시각과 31초 이내로 일치합니다. 이를 다른 모든 연도의 전수 검증으로 간주하지 않습니다. `npm test`는 이 외에도 절입 경계 전후, UTC+8/UTC+9 날짜 차이, 모든 일간의 시주, 윤달 검증, 시간 미상, 공유 개인정보 제거를 확인합니다.

### 지원 범위와 해석의 한계

입력은 **고정 한국 표준시 UTC+9** 기준입니다. 출생지에 따른 진태양시, 해외 시간대, 한국의 과거 표준시 변경과 서머타임은 자동 보정하지 않습니다. 해당 출생자는 보정한 표준시를 입력해야 하며, 결과와 폼에서 이 기준을 안내합니다. 절입에 매우 가까운 출생은 계산 정밀도 및 역서 차이 때문에 달라질 수 있습니다. 분까지만 입력하므로 같은 분 안에 절기가 바뀌는 경우에도 주의가 필요합니다.

원국은 위 기준으로 실제 계산하지만 운세·성격·궁합 풀이는 규칙 기반 전통 상징의 설명과 직접 작성한 이야기입니다. 직무 예시는 일간과 다른 확정 천간의 십성 5개 그룹을 같은 비중으로 묶어 고르며, 동률이면 월주 천간 관계를 우선합니다. 이는 용신·신강·신약 판정이나 직업 적합성 검사가 아닙니다. 실제 역량·경험·관심을 비교하기 위한 탐색 예시입니다. 과학적으로 검증된 미래 예측, 성격 검사, 재회·성공 확률이 아닙니다. 임의 운세·궁합 점수를 제거했고, 색과 아이템은 일간 오행을 테마로 고른 생활 제안입니다. 궁합은 일간·일지 비교에 한정하며 전통 명리학 전체의 궁합 감정은 제공하지 않습니다. 대운, 세운의 종합 감정은 아직 지원하지 않습니다.

## 결제 데모와 개인정보

실제 결제나 PG 연동은 없습니다. ‘결제 없이 데모 해금하기’는 화면 상태만 변경합니다. 결제 정보는 입력받지 않습니다.

계산과 해석은 브라우저에서 동작합니다. 별도의 AI API, 계정, 외부 사주 API 호출이 필요하지 않습니다. 이전 버전으로 저장된 데모 결과는 ‘이전 데모’라고 표시하며 실제 계산 결과로 취급하지 않습니다.

생년월일시와 달력 종류는 화면 메모리에만 유지합니다. 서버 전송이나 저장은 없습니다. 운세 보관 시 닉네임·사주 글자·오행·풀이·선택한 상황·실천 체크·선택한 부적과 응원 도장이 로컬 저장소에 남습니다. 입력한 날짜·시각과 변환한 음양력 날짜는 제거합니다. 공유 링크의 URL 조각에는 닉네임·해석 요약·캐릭터 이름과 테마만 포함되며 원국과 생년월일시는 포함되지 않습니다. 링크 내용은 수신자가 수정할 수 있으므로 공유 카드를 원국 계산 증명이나 인증 결과로 취급하지 않습니다.

실제 결제 연동 시에는 서버에서 결제 생성·검증 후 이용 권한을 저장하고, 상세 결과 접근을 서버에서 제한해야 합니다. 현재 브라우저의 `unlocked` 상태는 체험용으로만 사용합니다.

- `public/characters/`: 새 오행별 햄스터 삽화 5종. [삽화 경로·전체 프롬프트·제작 기록](public/characters/README.md).
- `public/fonts/`: 자체 호스팅한 Pretendard 글꼴과 OFL 라이선스.

## 상세 리포트 구성

1. 나를 읽는 이야기: 캐릭터, 어쩐지 익숙한 작은 장면, 강점·에너지 패턴과 전환 행동.
2. 일과 직업의 장면: 3가지 직무의 실제 하는 일과 하루, 분류 이유, 내 상황에 맞춘 이야기.
3. 회사에서의 대화법: 업무 상황, 그대로 말해볼 문장, 지킬 경계.
4. 가까운 사이의 레시피: 관계의 장면과 대화 문장.
5. 선택과 일상의 습관: 일상 자원과 결정 방식을 관찰하는 행동.
6. 계절이 더하는 이야기: 월지의 계절 상징과 실제 대표 오행 개수.
7. 몽글도사의 액운막기: 조급함·말실수·과한 부담·자책·걱정별 햄스터 삽화와 실천법 3가지, 응원 도장, 1080 × 1350 PNG 부적 카드.
8. 나를 위한 7일 실험: 체크 가능한 행동과 진행 표시. 보관한 리포트의 선택·체크 상태는 다시 열어도 유지됩니다.

홈 화면, 결제 전 사주 결과, 결제 안내에서 액운막기 삽화와 정보를 미리 보여줍니다. 일간 오행에 따라 기본 부적을 표시하며 원하는 테마를 직접 선택할 수 있습니다. 이는 실제 액운의 판정이나 보호 효능의 보장이 아닌 창작 응원 콘텐츠입니다. 기존 990원 데모 해금에 포함되며 추가 결제는 없습니다. 선택한 부적과 응원 도장은 보관한 리포트에 함께 저장하며 공개 결과 링크에는 넣지 않습니다.

리포트 하단에서 실제 사용한 일간·십성·월지와 해석 범위를 확인할 수 있습니다. PNG 공유 카드에도 캐릭터 삽화가 적용되며, 공유 링크에는 전체 유료 리포트나 체크 기록을 넣지 않습니다. 상세 리포트·부적 분기와 공유 정보 검증을 포함한 전체 22개 테스트를 통과했습니다.
